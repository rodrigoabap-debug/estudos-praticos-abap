# Estudos Práticos em ABAP

## Objetivo do projeto

Este repositório reúne exercícios e algoritmos desenvolvidos durante meus estudos em ABAP.

O objetivo é consolidar os conceitos fundamentais da linguagem, fortalecer minha lógica de programação e acompanhar minha evolução no desenvolvimento para o ecossistema SAP.

## Tecnologias utilizadas

- ABAP
- SAP
- Lógica de Programação

## Conteúdos praticados

- Estruturas de controle
- Tabelas internas
- LOOP
- READ TABLE
- SORT
- FIELD-SYMBOLS
- Manipulação de dados
- Resolução de problemas

## O que foi aprendido

Durante o desenvolvimento deste projeto, aprofundei meus conhecimentos nos fundamentos da linguagem ABAP por meio de exercícios práticos.

Também desenvolvi uma melhor compreensão da lógica de programação, da manipulação de dados e da importância de criar códigos organizados, legíveis e de fácil manutenção.

Este repositório representa parte da minha evolução nos estudos de ABAP e será atualizado conforme novos conhecimentos forem adquiridos.
